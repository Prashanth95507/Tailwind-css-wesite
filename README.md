# Tailwind-css-wesite
full of all the files ive made with tailwind css <br>

this repository contains the images needed for the gallery section <br>

This project is a simple, responsive image gallery website built using HTML and Tailwind CSS. It features a clean layout with navigation, a grid-based image gallery, and a footer with the home page with .<br>

The purpose of this project is to demonstrate basic front-end web development skills, including layout design, responsive grids, and utility-first styling with Tailwind CSS. <br> 

now the styling on these two webpages are made with the help of tailwind css <br> 

<br><u> the content of tailwind css applied to the webpages are the following: </u> <br> 

<br>
-grid : used to establish a grid which allows me to arrange the images in a neat way <br>
-grid-cols : helps to specify how many columns should be present on the page <br>
-mx : this is for the horizontal margin application <br>
-footer : A footer typically contains information about its section such as who wrote it, links to related documents, copyright data, and the like <br>
-nav : this is the navigation element that links to other pages or to parts within the page: a section with navigation links.<br>
-meta : The meta element represents various kinds of metadata that cannot be expressed using the title, base, link, style, and script elements.<br>
-body : it represents the content of the page






<br>HTML5 – structure of the webpage <br>
Tailwind CSS (via CDN) – styling and layout <br>
Responsive Design Principles – ensures usability across devices via use of tailwind css properties (sm, md, xl, lg) <br>

<br><b>Created as a beginner-friendly web development project to practice Tailwind CSS and responsive design.</b>
